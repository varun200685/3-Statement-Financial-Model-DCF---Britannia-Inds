# 3-Statement-Financial-Model-DCF---Britannia-Inds
•	Built a fully linked P&L, Balance Sheet, and Cash Flow model on 6 years of consolidated financials, projecting 3 years forward on driver-based assumptions with the Balance Sheet verified to tie out to zero variance in every projected year
•	Structured a dedicated assumptions layer so growth, tax, and margin inputs can be flexed without breaking the linkage across the P&L, Balance Sheet, and Cash Flow.
•	Extended the model with a DCF module, running a 5×5 WACC/growth sensitivity table where a WACC shift moved intrinsic value by ~13% (₹358 - ₹311)
